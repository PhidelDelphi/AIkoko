# Composition 语篇导入与识别

## 一、三种导入入口（教师操作）

| 入口 | 位置 | 适用 | 自动化程度 |
|---|---|---|---|
| 📋 一键粘贴 | 左侧栏底部 | 任何文本（复制原文+段首句+范文） | 自动识别段首句/范文/story |
| 📄 导入Word | 左侧栏 | docx 讲义 | 段落自动填入 |
| **PDF 自动识别** | ➕创建练习 → ⚙导入PDF | 试卷+答案PDF | **全自动建篇**（详见下） |

## 二、PDF 自动识别管线（核心）

```
① ➕ 创建练习（命名，如"审题训练01"）——一切导入进入当前练习，Excel/PDF都不会新建练习
② 导入试卷PDF（14页约40-60秒，等"✍ 读后续写已自动转入"toast）
   → 自动建篇"读后续写（练习名）"：原文story + 段首句openers
③ 导入答案PDF（等"📖 参考范文已自动回填"toast）
   → 步骤⑧自动填入续写范文（两段精确切分）
```

**导入互斥**：一次只能处理一个PDF，处理中再导入会提示等待——**必须等每个文件完成toast再导下一个**（并发会竞态）。

## 三、识别规则（设计定论）

### 段首句（openers）——两种试卷格式
- **标准式**：`Paragraph 1: xxx` / `Para 1: xxx` / `Paragraph One: xxx` 独立行
- **答题卡式**：`As he flipped... mist.________`（句子+答题线，同一视觉行或句子行+纯线行）
- 识别位置：切分层先把答题卡式**标准化为 Paragraph N:**（必须在 stripAnswerLines 之前——后者会吃掉下划线），再由 essay 层统一正则识别
- 答题线（`____`）、"注意：/1.续写词数/2.请按…"指令行全部剔除

### 原文（story）
- examIndex['Continuation Writing'] 切片 → 清洗 → **兜底过滤**：选项行（`41. A. crowded...`）、题干行（`35. What...`）、孤立选项、中文页眉、<25字母碎片全部剔除
- 长度合理的自然段保留（Jake篇=7段）

### 范文（step8）——段首句锚定切分法
- 答案PDF提取"参考范文/One possible version"标记后英文段（**从后往前**找：应用文范文在卷首、续写在卷尾）
- 提取时**听力起始行（`Text N` / `M:` / `W:`）即截断**（范文后常紧跟听力原文）
- 回填前用**试卷侧段首句定位**：段首句1前4词之前全弃（剔除应用文范文）→ 段首句2前4词处分两段 → 段2按段落边界(\n)截断（隔离完形解析等粘连内容）+ 听力/中文兜底
- **只填占位**：步骤⑧已有内容（非"待生成"占位）不覆盖

### 防覆盖写保护
- `window.__cwParsed`（续写解析结果）跨导入共享，但**有段首句的结果才可覆盖**（答案PDF的范文区会产出垃圾解析，防其覆盖试卷正解）
- examIndex 的 CW 键：答案版（无 Paragraph 标记/注意指令）不覆盖试卷正题

## 四、故障排查手册（按症状）

| 症状 | 根因 | 处置 |
|---|---|---|
| 导PDF后Composition无篇 | ①没等解析完成（40-60秒）②浏览器缓存旧JS | 等toast；Ctrl+F5强刷 |
| 段首句"未识别" | 试卷格式特殊（非上述两种） | 手动填：篇目步骤①旁编辑openers |
| 听力原文混入范文 | 范文后紧跟听力（历史bug已修） | ✏️编辑步骤⑧手动删 |
| 应用文范文混入 | 定位切分未生效（历史bug已修） | ✏️编辑清理 |
| 范文粘成一段 | 未按段首句2切分（历史bug已修） | ✏️编辑手动分段 |
| Excel导入新建了练习 | 旧版逻辑（已改：永远导入当前练习） | 升级JS |

## 五、手动兜底（一键粘贴格式规范）

自动识别失败时的保底路径，粘贴文本按此结构可100%识别：
```
<原文段落若干>
续写段首句：
Paragraph 1: <段首句1>
Paragraph 2: <段首句2>
范文：
<范文两段>
```

## 六、维护要点（AI会话用）

**代码位置**（全部在 `E:/AIkoko/mindmap嵌入版本/`，⚠️原版VScode for AFR禁改）：
- `script-v2.js`（=script.js副本，改动需双份同步+index.html缓存参数t=刷新）：
  - `parseContinuationRaw`：续写独立解析（原文+段首句）
  - `extractSampleFromPages`：范文提取（返回纯段数组）
  - `importPdf/importPdfCore`：互斥锁`window.__pdfImporting`包裹
  - 收尾联动块：examCwParsed优先→ingest建篇；范文段首句锚定切分→fillSample回填
  - `trimExamSlice` CW分支：答题卡段首句标准化（必须在stripAnswerLines前）
  - CW区boundary忽略页眉（"试题"页眉在pdf.js文本流常落在答题区后）
- `essay-review.js`：`ingestFromExam`（预清洗+建篇+story兜底过滤）、`fillSampleFromExam`（回填+占位判定）

**pdf.js 文本层四大陷阱**（改此管线必读）：
1. textContent是**视觉行块**非语义段落（原文/答题区各粘成一行）
2. **页眉页脚在文本流中乱序**（"试题"页眉可能排在页面内容之后）
3. 答案PDF范文后**紧跟听力原文**（Text 1 M:...）
4. 范文段1段2间**常无中文行分隔**（粘连成块）

**缓存参数纪律**：每次改JS必刷新index.html的`?t=`/`?v=`参数，且用`document.querySelector('script[src*=xx]').src`验证实际加载版本——参数链断裂=改了没生效=白测。
