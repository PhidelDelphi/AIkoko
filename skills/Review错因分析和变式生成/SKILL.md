# AFR试卷选项分析 + 变式巩固 JSON 生成

用户备课时发来试卷PDF（可加成绩Excel），你负责生成AFR系统可导入的分析JSON。

## 触发条件

用户发来试卷PDF文件（通常在 `E:/AIkoko/VScode for AFR/Data/` 下）并说"分析"、"变式"、"备课"等词。

## 必要输入

| 文件 | 用途 | 缺失时 |
|---|---|---|
| 试卷PDF | 提取题目原文、题干选项 | **必须**，请用户提供 |
| 成绩Excel（合并五表版） | 双班红黄题清单、TOP2错误选项 | 用PDF独立预判（标注"预判"） |

## 工作流程

### 第1步：解析成绩Excel（有则必做）

```python
# 用 成绩合并/scripts/merge_practice.py 或已合并的xlsx
# 逐班计算：班级正确率 < 70% = 红黄题
# 每题：排除正确答案后按人数排序取TOP2错误选项
# 输出：{class9: [{q, rate, ans, top2: [(letter, count), ...]}], class11: [...]}
```

关键解析要点：
- 成绩表"学生明细-题号排序"工作表含双班分段（09班/11班各一段）
- 班级得分率可能是百分比字符串("77.19%")或小数(0.7719)
- 正确答案在"答对人数"列（如"C:39"）
- 填涂矩阵在"客观题填涂"工作表（有字母→用矩阵推名单；无→用明细兜底）

### 第2步：读试卷PDF

```python
import fitz
doc = fitz.open(pdf_path)
for i in range(len(doc)):
    print(f'===== P{i+1} =====')
    print(doc[i].get_text())
```

重点提取：**红黄题的题干+全部选项原文**（这是分析"定位句/干扰项设计"的必需品）。

### 第3步：逐题×TOP2选项写分析

每条分析包含：
- **errorType**：十二类错误体系之一（见下方taxonomy）
- **cause**：含真实人数（如"34人选择C——"）+ 错因分析 + 排除口诀
- **variant**：一道新语料同类陷阱变式题

**十二类错误选项类型体系**（师生统一用语）：

| 类型 | 界定 |
|---|---|
| 无中生有 | 选项信息原文完全未提及 |
| 反向设置 | 与原文表述方向相反 |
| 张冠李戴 | 把甲对象的内容安到乙头上 |
| 以偏概全 | 局部细节冒充整体 |
| 偷换概念 | 句面相似但核心词义已变 |
| 曲解文意 | 对原句作似是而非的歪曲 |
| 层级/分区混淆 | 混淆并列要素的层级 |
| 近似值陷阱 | 图表数值临界差一档 |
| 让步处设错 | 抽让步从句表象词当情感答案 |
| 代词无先行词 | 七选五代词找不到指代 |
| 位置错配/衔接不当 | 内容合理但属于其他设空 |
| 近义干扰 | 两选项表义相近须凭限定词分辨 |

**变式命制规则**：
- 新语境新语料，不照抄原文
- 考点与陷阱类型与原题同构（错哪类→变式考哪类）
- 每道变式：题干（1-3句小语料）+ 四选项 + 答案 + 简析（回贴错误类型标签）
- 干扰项设计意图需与原题同类

### 第4步：生成JSON

```json
{
  "assignment": "作业名（与AFR中导入Excel后的作业名一致，用于自动匹配）",
  "source": "AI分析(试卷PDF+AFR双班实测数据)",
  "generatedAt": "日期",
  "classes": {
    "class9": [
      {
        "id": 题号,
        "knowledgePoint": "考点（如：推理判断·人物路径概括）",
        "options": [
          {
            "letter": "错误选项字母",
            "errorType": "错误类型（十二类之一）",
            "cause": "N人选择X——错因分析+排除口诀",
            "variant": {
              "stem": "题干（新语料）",
              "options": {"A": "...", "B": "...", "C": "...", "D": "..."},
              "answer": "正确答案字母",
              "analysis": "简析（含同类错误类型标签）"
            }
          }
        ]
      }
    ],
    "class11": [...]
  }
}
```

**注意**：
- 两个班各自独立计算红黄题和TOP2（同题可能不同班不同TOP2）
- 选项值不要带字母前缀（渲染层会自动加"A."）
- 七选五变式格式："根据短文内容，从短文后的选项中选出能填入①处空白的最佳选项。"
- 主观题（语法填空/应用文/续写）不生成变式（系统内已有分数段统计）
- 作业名从Excel总览表标题行提取（如"2026-2027学年度第一学期高三第一次诊断练习"）

### 第5步：保存到Data文件夹

```python
# 保存路径
path = f'E:/AIkoko/VScode for AFR/Data/{练习名称}-analysis.json'
# 练习名称与PDF文件名保持一致（如"高三上补充练习05"→"高三上补充练习05-analysis.json"）
```

### 第6步：告知用户使用方法

```
1. 打开AFR → Ctrl+Shift+R 强刷
2. ⚙ 导入成绩Excel（如未导入）
3. ⚙ 导入 {文件名}-analysis.json → 自动按作业名匹配挂载
4. Review点红黄题 → ⚔ 变式训练弹窗
```

## 质量标准

- cause 必须引用真实人数（"34人选择C——"）
- variant 的干扰项必须与原题同类（不能换成无关陷阱）
- analysis 回贴错误类型标签（让学生核对归因是否同型）
- 语言精炼（cause 2-3句、analysis 1-2句）
- 选项值干净（不带字母前缀、不带多余换行）

## 与AFR系统的对接

- 导入按钮：⚙面板 🤖 Import AI Analysis
- 作业定位：JSON的`assignment`字段与AFR作业名**模糊匹配**（忽略连字符/空格差异）
- 渲染：红黄题详情卡出现"⚔ 变式训练"按钮 → 弹窗显示TOP2×(类型+错因+变式)
- AI标记：所有内容带"🤖AI生成·教师审定"标记

## 常见问题排查

| 症状 | 原因 | 解决 |
|---|---|---|
| 导入提示"没有匹配到任何题目" | 作业名不匹配或未导Excel | 先导Excel；检查assignment字段 |
| 弹窗无变式 | 该题非红黄（正确率≥70%） | 正常——变式只属于红黄题 |
| 选项显示重复字母 | JSON选项值带了"A."前缀 | 渲染层已做防御剥离，新数据应避免 |
| 两个班内容相同 | 未按班分别算TOP2 | 重跑第1步确保class9/class11各自独立 |
