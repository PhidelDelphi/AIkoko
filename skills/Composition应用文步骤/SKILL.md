# Composition 应用文步骤 · 八步评讲生成技能

> **版本**：2026-10-06 定稿并实战验证（示例二：公园美术课分享邮件，与示例一邀请函构成语域两极对照）。
> 完整可运行范例：`示例-EnglishParty邀请函.json`（邀请师长·半正式偏正式·将来时）、`示例-公园美术课分享邮件.json`（分享给朋友·非正式·过去叙事）。

## 技能定位

**输入**：教师发来任意应用文题目（粘贴题干文本 / 试卷PDF+答案PDF / 图片转录，体裁不限：邀请信、建议信、申请信、感谢信、通知、倡议书、征文投稿、发言稿、分享邮件等）。
**输出**：应用文八步评讲 JSON（单篇格式），教师在 AFR Composition 页「⬆️ 导入篇目」一键载入。
**触发词**："应用文八步"、"生成应用文评讲"、"按八步分析应用文"、"Composition应用文步骤"。

**与其他技能的分工**：本技能管八步评讲骨架（①-⑧）；步骤⑦评价升格的深度数据（bandSpec 三维定制/下水文）由 `composition-eval-upgrade` 技能补充；PDF 自动识别题干建篇由页面管线自动完成（本技能在其留白处填充八步内容，见第七节）。

## 一、设计哲学（先读，决定每一步的口味）

| | 读后续写 | 应用文（本技能） |
|---|---|---|
| 源泉 | **原文**（伏笔=隐性资源） | **题干**（要点=显性要求） |
| 追求 | 合理 + 生动 | **完整 + 得体** |
| 训练 | 想象力 | **交际力** |

高考应用文本质是**交际行为，不是信息清单**——"要点齐全但语气不得体依然丢分"。八步全程围绕这条主线：

```
①读题（事实+陷阱+任务卡）→ ②定调（语用四问辨析）→ ③搭架（凤头猪肚豹尾+字数预算）
→ ④建构（四把梯子爬出层次与思想）→ ⑤病理（12类正反对照）→ ⑥语料（句式全家桶）
→ ⑦评价升格（五维定价）→ ⑧佳作（词数体检+五维收束）
```

步骤顺序为**结构先行序**（2026-10 用户定）：先定三段骨架（③），再往骨架里填肉（④）——贴近学生真实动笔路径，且"详略铁律"需要先知道哪段是主体。

## 二、八步框架规范（每步：目标 / 结构 / 生成规则）

### ① 审题拆解 · 情境五问 —— 事实提取层

**分工原则：①只管"题干说了什么/必须读出什么/哪里容易读错"，不谈语气口吻（那是②的决策产物）。**

- 五问固定：Who am I? / To whom? / What? / Where? / Why?
- 每问三行（rowLabels 固定 `['题干信息','隐含要求','易错预警']`）：
  - **题干信息**：明示事实（身份/对象/文体/载体/目的）
  - **隐含要求**：题干没直说但必须读出（如"邀请≠通知，只能恳请不能布置"）
  - **易错预警**：本题高频病症一句话（自封头衔/人称写第三方/通知口吻/漏落款超词/目的降级告知）——**①写"警惕什么"（一句话），⑤写"病例长什么样"（完整病句），不重复**
- 末尾**任务卡合成**（特殊卡，字段 card/tag/hint）：一句话任务定义 + 语用标签
  - 语用标签格式：`［语域格位 · 温度 · 联结配方 · 时态基调］`（由②判定后回填），两个实战对照：
    - 邀请外教：`［半正式偏正式 · 热情留白 · 联结配方：契合＋感情＋身份 · 时态：将来为主］`
    - 分享经历给朋友：`［非正式偏半正式 · 热在画面 · 联结配方：契合＋感情 · 时态：过去叙事＋现在感想］`
  - **时态基调随题型变**：邀请/通知=将来为主 · 分享经历=过去叙事+现在感想 · 建议=现在为主——⑤"时态混乱"卡的 bad 句要按本题时态定制（如叙事题的 `Last Friday I paint...`）

### ② 定位基调 · 四问辨析台 —— 语用决策层

四问标题**四字对仗固定**，每问 4 个选项（`opts:[{t, v, why}]`），错误选项=真实学生病症方向，学生先揣摩点选再揭示（学生先行）：

| 问 | 框架（不变量） | 换题只改 |
|---|---|---|
| ①**交际目的** | 四型：告知/促成/表现/修复（**分享=告知的温度版**，见下） | 本题落点与各 why 例句 |
| ②**关系定位** | 语域四格：正式→半正式偏正式→平视→非正式 | 双方关系分析与落点格 |
| ③**情感分寸** | 四档：施压/得体留白/零度/卑微 | "该多热"的判断理由 |
| ④**联结路径** | 道理✗单向 / 契合+感情+身份=三通道 | 三通道的本题例句与配方 |

**分享型落点写法**（经历分享题，2026-10 实战验证）：B 选项写成"如临其境地共享这次经历（分享型：告知＋画面＋温度）"——分享=高情感的告知，判断法："对方读完想回 That sounds amazing!"。朋友间用不上"抬身份"通道（D 选项标 false 并注明"朋友间用不着 honor 这套"）。

- **金句必须保留**："虚拟语气=把决定权还给对方"（③问核心）；"联结三通道：契合是'正好'、感情是'想你'、身份是'配您'"（④问核心）
- 总结 `a`：落点 + 一般性对照（如"通知=告知·邀请/请求=促成·申请=表现·道歉=修复"）
- 多个 v:true 允许（配方题，如邀请=B+C+D）

### ③ 谋篇布局 · 凤头猪肚豹尾 —— 结构层

- `overview` 脉络卡一句："凤引出来意 → 猪充实理由与安排 → 豹推动行动"
- `sections` 三卡固定（icon/par/budget/goal/micro/plots）：

| 段 | 预算（固定） | 达成 | 微结构 |
|---|---|---|---|
| 🐦 凤头·开头段 | 约15词·1-2句 | 3秒定向+定调（承②） | 呼语→(自我介绍·仅当对方不认识你)→目的句→背景句 |
| 🐗 猪肚·主体段 | 约45词·3-4句 | 得分点全展开 | 总起句→层次①→层次②→个性化句（**层次怎么爬梯→④**） |
| 🐆 豹尾·结尾段 | 约20词·1-2句 | 促成行动+留余韵 | 行动句(带期限)→期待句 |

- 每卡 plots 给本题的具体句子示范 + 一条自检（凤头不讲废话/猪肚问句全答完/豹尾是期待不是通知）
- 换题改：goal/micro 里的例句与自检；**预算与凤猪豹结构不变**

### ④ 建构要点 · 四把梯子 —— 层次与思想层

**总纲（必保留）："梯子爬到顶，就是思想性"——层次性=爬的过程，思想性=顶层风景。学生作文"平"的病根是梯子只爬第一级（罗列事实）从不登顶。**

四把梯（`items`，固定框架）：

| 梯 | 台阶 | 适用 |
|---|---|---|
| ⛏ 深度梯（由表及里） | 现象→原因→本质/价值 | 分析"为什么喜欢/推荐" |
| ⛰ 高度梯（由小到大） | 个人→集体→社会 | 影响分析、解决方案、意义 |
| 🪜 认知梯（由低到高） | 了解→实践→创造 | 活动安排、收获成长 |
| 🎈 抽象梯（由实到虚） | 具体事实→意义价值 | 结尾升华、点出价值 |

- guide=选梯指南（80词选**一把梯爬两三级**即可，不必四把全上）
- **`build` 本篇建构（本步灵魂，支架的应用）**：
  - `pick`：本题选梯决策（哪几个得分点各配哪把梯）
  - `runs[]`：每梯一卡——梯名+对应要点+`steps[]`三级台阶（lvl+**本题真句**：起点句→中间句→登顶句）+`note`成果注（与③猪肚"层次①②/个性化句"对接）
- fuLabels 固定 `['台阶','示范']`

### ⑤ 反馈问题 · 病理对照 —— 诊断层

12 类问题**固定**，按病源五分组（溯源前四步+⑦五维），每条 `{t, src, bad, good, note}`：

- **审题病·源自①**：立意偏离主题 / 要点遗漏缺失 / 格式杂糅混乱 / 人称错位失联
- **基调病·源自②**：交际效果欠佳
- **结构病·源自③**：结构松散凌乱 / 要点重复冗余
- **建构病·源自④**：内容宽泛空洞 / 思想浅显单薄 / 内容陈旧老套
- **语言病·源自⑥**：语言单调简单 / 时态混乱错位

- `src` 格式：`"组名 · 五维N维度名"`（映射到⑦五维）
- **bad/good 必须是本题的真句对照**（红✗/绿✓），note 回指前步（"回看①任务卡""②情感分寸的落点""④深度梯的终点"）
- 语言类卡可挂 `checks`（勾选自查+跳⑥语料按钮，`{q, s6:语料框索引}`）

### ⑥ 输入语料 · Idiomatic, not literal —— 语言层

**段位结构**（与③凤猪豹贯通），猪肚扩容：

```
Para 1 · 凤头        2框 4例（目的句起手 / 背景句）
Para 2 · 猪肚 主体段  4框 10例 ← 主体段重点：总起时间地点 / 活动展开 / 个性化邀请 / 价值升华
Para 3 · 豹尾        2框 4例（行动句 / 期待句）
```

- 每框 `{p, q, corpus:[2-3组{tell, show, skills}]}`——✗tell 直白 ➜ ✓show 地道
- **句式全家桶全覆盖**（每框至少触达两类）：with复合结构 / 三大从句（定语·状语·名词性）/ 非谓语（to do·doing·done·分词短语）/ 倒装（Not only...·省略if的Should you...）/ 强调句（It is...that）/ 虚拟语气（would...if you could·if you were to）/ 无灵主语
- show 句中目标词块用 `<b>` 加粗

### ⑦ 评价升格 —— 评价层（已定稿，页面内置）

五维（用户定稿）：内容完整性和连贯性 / 要点层次性和思想性 / 语言丰富性和得体性 / 结构严谨性和流畅性 / 语法规范性和准确性。15分制五档、要点覆盖清单（fuyao 按题干逐条拆）、十问自查、升格方向。**本技能只需在 JSON 里给 `fuyao`（题干要点清单 3-5 条）**，深度数据（bandSpec/下水文）走 composition-eval-upgrade 技能。

### ⑧ 共赏佳作 —— 收束层

- `text`：范文全文（`<b>`加粗亮点词块，段落用 `<br><br>` 分隔，**三段结构**：凤1段猪1段豹1段；续写则两段各约75词）
- `eval[]`：五维点评 5 条 `{dim, comment}`——**每条必须回指前步**："①的任务卡兑现""④深度梯表→里→顶走完""②语域的教科书示范""凤15猪45豹20（词数体检可验证）""⑤语言病一条不犯"
- 页面自动算词数体检（分段对照预算），不需生成

## 三、迁移指南：不变量 vs 变量

### 不变量（任何应用文都不改）
八步名称与顺序 / rowLabels / fuLabels / 四问框架类型学 / 四把梯框架 / 12类病理分类与分组 / 凤15猪45豹20预算 / 语料段位结构（2+4+2框）与句式全家桶清单 / ⑦五维。

### 变量（换题重写）
story 题干 / ①五问三行内容+任务卡 / ②四问的落点与 why 例句 / ③三卡微结构例句与自检 / ④四梯的示范句+build 全部（选梯+三级真句）/ ⑤12条 bad/good/note / ⑥全部 tell/show 例句 / ⑧范文+五维点评。

### 常见体裁速查（落点参考）

| 体裁 | 目的型 | 语域常落 | 首选梯 | 格式要点 |
|---|---|---|---|---|
| 邀请信 | 促成 | 偏正式（师长）/平视（同学） | 深度+认知 | 三件套；期待回复带期限 |
| 建议信 | 促成（说服） | 看对象 | 高度（个人→集体）+深度（原因） | 建议要可操作，语气协商 |
| 申请信 | 表现（自荐） | 正式 | 高度（我能贡献什么） | 亮资质+表决心 |
| 感谢信 | 修复/深化 | 偏正式 | 深度（事→情→义） | 具体事例承载感情 |
| 通知 | 告知 | 正式 | ——（不需登顶） | 标题式，we 人称，**无称呼落款** |
| 倡议书 | 促成（集体行动） | 正式偏热 | 高度（个人→社会） | 标题+称呼可泛化，结尾呼吁 |
| 征文投稿 | 表现+联结读者 | 半正式 | 抽象（事实→意义） | **可加标题**，直呼读者 you |
| 发言稿 | 促成/感染 | 看场合 | 高度+抽象 | 开头问候结尾致谢 |
| **分享邮件**（经历/见闻） | 分享（告知的温度版） | **非正式**（朋友D格） | **深度梯**（作品→体验→感悟） | 画面细节承载温度；**过去叙事+现在感想** |

## 四、生成工作流

1. **读题**：提取题干全部信息（身份/对象/文体/要点列表/注意项/格式块）
2. **定型**：过一遍②四问（自答定落点）——这一步的答案决定全文所有例句的口味
3. **搭架**：按③写三卡；预算 15/45/20 微调可（题干词数非80时按比例）
4. **爬梯**：选定本题 1-2 把梯，写 build 三级真句
5. **病例**：12 类逐条写 bad/good（bad 必须是"这类学生真会这么写"的句子）
6. **语料**：按段位 2+4+2 铺 18 例左右，对照句式全家桶查漏
7. **范文+点评**：写范文（自己先过一遍词数体检），五维点评回指前步
8. **组装 JSON**（见 schema），交付桌面 `作文评讲-<篇名>.json`

## 六、PDF 管线配合（教师侧工作流，2026-10 实战定稿）

页面管线（嵌入版已上线）与本技能的接力关系：

```
教师发来 试卷.pdf + 答案.pdf
→ 试卷PDF导入：自动建"应用文（卷名）"篇（题干入①侧栏，八步留白）
→ 本技能生成 JSON → ⬆️ 导入篇目 → 八步内容就位（题干侧栏不受影响）
→ 答案PDF导入：范文自动识别回填⑧（带自动分段，词数体检即时可看）
```

管线行为要点（教师不必关心，生成时可参考）：
- **只导答案PDF也行**：库里无应用文篇时管线自动建篇（题干占位待补）——题干后经试卷PDF或手填
- **题干锚点**：`假定/假设你是` 或句首 `你是李华`；范文识别靠 Dear…/落款签名（Yours sincerely / Yours, / Best wishes 均可）+词数 60-220
- **PDF分段**：按行距双峰自动分段（顶格无缩进也能分），范文段落还原可信
- 若走 PDF 管线建过篇，本技能 JSON 的 `story` 会覆盖占位题干——**story 必须从试题原文摘录**，别自拟

## 七、实战两极对照（框架迁移力的证明）

两个已验证范例恰好落在语域标尺两端，证明"四问/四梯/12病/凤猪豹"框架的普适：

| 维度 | 示例一：English Party 邀请函 | 示例二：公园美术课分享邮件 |
|---|---|---|
| 交际目的 | 促成（答应来+表演） | 分享（如临其境+温度） |
| 语域 | B格 半正式偏正式（师长） | D格 非正式（朋友） |
| 情感分寸 | 热在诚意，留白在决定权（虚拟语气） | 热在画面，收在真情（细节承载） |
| 联结配方 | 契合+感情+抬身份（B+C+D） | 契合+感情（B+C，用不上D） |
| 时态基调 | 将来为主（is scheduled / will be held） | 过去叙事+现在感想（painted / realize） |
| 主梯 | 认知梯（了解→实践→创造）+深度梯 | 深度梯（作品→沉浸→感悟）+抽象梯收顶 |
| ⑤高频时态病 | I will invite（此刻进行误将来） | Last Friday I paint（叙事忘过去） |

生成新题时先在本表定位它落在哪一极（或中间态），②④⑤⑥的口味就有了参照系。
