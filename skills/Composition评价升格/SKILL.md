# Composition 评价升格 · 步骤⑦ JSON 生成技能

为 AFR「mindmap嵌入版」Composition 页第⑦步生成完整的评价升格数据。

**输入**：试卷PDF（含作文题目+参考范文）
**输出**：单篇 JSON → 写到 `C:\Users\Delphi\Desktop\评价升格-<卷名>.json`

## 页面架构概览（V3版）

页面分两Tab：`A. 评价` 和 `B. 升格`

### A. 评价（三步）
```
第一步 · 五维雷达评维（SVG五边形，每维3星，打星自动推档）
第二步 · 综合定档（打星满五维推算 + 手动点选五档条对拍 + 双栏：左官方原文/右本篇三维定制）
第三步 · 互评与自评（双列卡片：互评卡|自评卡，各有评价者/档位/得分/1.亮点2.问题3.建议/提交按钮）
→ 评价反馈区（汇总：评价数/平均档/区间 + 逐条展示）
```

### B. 升格（两步）
```
第一步 · 问题自反馈（十问五维分组，checkbox多选，勾选=改进点）
第二步 · 针对性升格（原文→升格方向→改文→对比卡→留痕上墙）
→ 班级升格墙（卡片流+✕删除）
```

## 二、两种文体的五维定义（用户定稿·不可改动）

### 读后续写（cont）
| # | 维度 | 说明文字 |
|---|---|---|
| 1 | 情节合理 | 续写内容贴合原文主线，情节合理、有起伏，人物情感发展自然，紧扣故事主题 |
| 2 | 内容完整 | 完成两段给定开头的任务，要点覆盖到位，情感闭环，满足故事续写要求 |
| 3 | 语言丰富 | 词汇、句式多样化；恰当使用非谓语、复合句、描写性表达（动作/神态/环境） |
| 4 | 语法规范 | 时态、主谓一致、拼写、标点错误少，不出现严重影响理解的硬伤 |
| 5 | 衔接顺畅 | 句间、段内逻辑衔接自然，善用连接词，行文流畅，段落过渡顺滑 |

### 应用文（prac）
| # | 维度 | 说明文字 |
|---|---|---|
| 1 | 内容完整性和连贯性 | 题干要求的要点逐条覆盖？无遗漏无无关？内容与题干情境、对象身份连贯一致？ |
| 2 | 要点层次性和思想性 | 要点按逻辑递进（背景→安排→期待），不堆砌？有深意、有情感温度，不止表面信息？ |
| 3 | 语言丰富性和得体性 | 句式多样（高级结构/功能句/多样词汇）？用词得体（符合对象身份，不生硬不过分随意）？ |
| 4 | 结构严谨性和流畅性 | 段落功能清晰（一般2-3段）？衔接过渡顺滑（连接词/指代/词汇链自然）？ |
| 5 | 语法规范性和准确性 | 时态/主谓一致/拼写/标点错误少？格式要素对（称呼/落款/Li Hua）？词数达标？ |

## 三、官方五档标准（评分参考原文）

### 读后续写（25分）
- 评分原则：从内容、语言表达和篇章结构三个方面考虑
- 五档 21~25：融洽度高，衔接合理，内容丰富有逻辑；多样恰当的词汇语法，个别小错不影响；有效衔接手段，结构清晰连贯
- 四档 16~20：融洽度较高，衔接较合理，内容较丰富；较恰当多样，些许错误不影响；较有效连接，较连贯
- 三档 11~15：关系较密切，一定衔接，内容基本合理；基本准确，一些错误基本不影响；简单连接，基本连贯
- 二档 6~10：关系较远，衔接较差，内容不够丰富；单调有限，错误较多部分影响；较少连接，不够连贯
- 一档 1~5：关系较差，衔接差，内容不合理不丰富；单调有限，错误很多严重影响；不连贯，缺乏完整性

### 应用文（15分）
- 评分原则：从内容要点覆盖度、语法结构与词汇的准确性和多样性、语句间连接与篇章连贯、格式与交际得体性四方面考虑
- 五档 13~15：完全完成任务，覆盖所有要点，较多语法结构词汇（些许错误为尝试复杂结构所致），有效连接结构紧凑，完全达到写作目的
- 四档 10~12：完成任务，漏1-2次重点但覆盖主要内容，满足需求基本准确，简单连接比较紧凑，达到写作目的
- 三档 7~9：基本完成任务，漏一些内容但覆盖主要内容，满足需求有错误不影响理解，简单连接基本连贯，基本达到目的
- 二档 4~6：未恰当完成，漏掉或未描述清楚一些主要内容，单调有限错误较多影响理解，较少连接缺乏连贯
- 一档 1~3：未完成，明显遗漏主要内容，单调有限错误严重影响理解，缺乏连接内容不连贯

## 四、bandSpec 本篇三维定制生成规则

对每个档位，针对**当前这篇作文的题目和范文**，写三维定制要求：

### 读后续写三维
- **内容**：这篇续写在第N档需要覆盖哪些情节节点？回收哪些伏笔？细节密度要求？
- **语言**：这篇续写在第N档需要用多少下划线关键词？几种句式？动词精度要求？
- **结构**：这篇续写在第N档段首句衔接要求？两段呼应要求？结尾克制度？

### 应用文三维
- **内容**：这篇应用文在第N档需要覆盖哪些要点？扩展到什么程度？
- **语言**：这篇应用文在第N档需要多少高级结构？功能句要求？
- **结构**：这篇应用文在第N档分段要求？格式/语域/词数标准？

**硬规则**：
- 五档写最具体（情节路径/要点清单/伏笔列表）
- 一档写最简略（只描述"缺什么"）
- 引用题干的具体信息（人物名/活动名/物品名），不用泛化表述

## 五、十问自查生成规则

### 按五维分组，每维2题，共10题
- 每题是问句格式，引导学生自查
- 题目要**结合本篇作文的具体内容**（引用人物名/活动名/伏笔名）
- 覆盖该文体最高频的问题类型

### 读后续写十问参考模板
```
情节合理：
  ① 我的续写有没有"飞"？每步能在原文找到依据吗（引用人物名）？
  ② 人物情感变化有过程吗——从___到___到___，是渐变还是突变？

内容完整：
  ③ 两段任务都完成了吗——P1（___→___→___）P2（___→___→___）？
  ④ 关键伏笔回收了吗——列出本文的具体伏笔？

语言丰富：
  ⑤ 我的情感是"演"出来的还是"说"出来的？圈出情绪词个数
  ⑥ 有没有一条动作链（≥3个连续动作）？有没有独立主格或with？

语法规范：
  ⑦ 全文时态统一过去时了吗？
  ⑧ 主谓一致/单复数过了吗？

衔接顺畅：
  ⑨ 段首句之后紧接情节推进了吗？两段之间有呼应吗？
  ⑩ 连接词/指代/词汇链自然吗？
```

### 应用文十问参考模板
```
内容完整性和连贯性：
  ① 题干要点逐条覆盖了吗？
  ② 内容与题干情境连贯吗？有没有写偏、写无关的？

要点层次性和思想性：
  ③ 要点按逻辑递进吗（背景→安排→期待），不是平铺堆砌？
  ④ 要点有思想性吗——有深意、有情感温度？

语言丰富性和得体性：
  ⑤ 有≥2处高级结构吗（if从句/with/非谓语）？
  ⑥ 用词得体吗——符合对象身份（对朋友自然/对外教礼貌）？

结构严谨性和流畅性：
  ⑦ 段落功能清晰吗（一般2-3段，一段一个功能）？
  ⑧ 衔接过渡顺滑吗——连接成分≥2处？

语法规范性和准确性：
  ⑨ 语法硬伤自查（常见错误列举）+ 拼写标点过一遍
  ⑩ 格式要素对吗（称呼/落款/Li Hua）？词数达标？
```

## 六、升格方向标签 + 示例句

### 读后续写
```
dirs: ["动作链","无灵主语","独立主格","with复合结构","对话点缀","环境烘托","短句造势","比喻拟人","非谓语压缩","五感细节"]
srcPH: "例：He cleaned the room carefully."
upPH: "例：He *rolled up the old carpet, *stacked the boxes neatly and swept the floor, *stirring up clouds of dust."
```

### 应用文
```
dirs: ["if从句","with复合结构","非谓语压缩","被动语态","固定搭配","连接成分","高级词块","礼貌句式"]
srcPH: "例：The party will hold in our school hall."
upPH: "例：The party *will be held* in our school hall, *with a variety of English activities *ranging from songs to short plays."
```

**硬规则**：示例句必须与当前作文内容相关（同类场景），不能用另一个文体的句子。

## 七、范文（sample）的写法

范文 = **故意含典型错误的下水文**（不是满分范文），供课堂升格用：
- 读后续写：含时态错误、单复数错误、情感"说"而非"演"、句式单调等
- 应用文：含 invite you join（缺to）、will hold（缺被动）、There will have（缺be）等
- 错误量控制在2-4处，学生可以在B区自查发现

## 八、生成流程（AI执行步骤）

1. **读PDF** → 识别是读后续写还是应用文
2. **提取**：题目要求（含下划线关键词/要点/段首句）+ 参考范文
3. **按模板填充**：五维→五档→bandSpec（本篇定制）→十问（本篇定制）→升格方向+示例句
4. **写下水文**（含错误的sample，参考范文改写，植入2-4处典型错误）
5. **组装JSON** → 写盘 → node校验
6. **告知教师**：文件位置 + 在V3页面如何加载
