# 成绩合并（学测成绩文档四合一）

把导出系统每次下发的每班 2 个 xlsx（N 个班共 2N 个文件）合并成 1 个总文档：
全部样式保真、题号表头自动带题型前缀、内置逐格校验。

## 快速使用

### 方式A：在 ZCode 里说一句话（自动触发已安装的技能）
> "用四合一/成绩合并，把 XX文件夹 的成绩合并成 XX.xlsx"

### 方式B：在 VS Code 终端直接运行脚本（本文件夹独立可用）

Git Bash：
```bash
PYTHONPATH="E:/AIkoko/Zcode for this item/pylibs" \
python "E:/AIkoko/Zcode for this item/成绩合并/scripts/merge_practice.py" "<原始文件夹>" "<输出文件.xlsx>"
```

PowerShell：
```powershell
$env:PYTHONPATH="E:\AIkoko\Zcode for this item\pylibs"
python "E:\AIkoko\Zcode for this item\成绩合并\scripts\merge_practice.py" "<原始文件夹>" "<输出文件.xlsx>"
```

参数（可选）：
- `--backup <路径>`：输出文件已存在时，先把旧文件备份到该路径再生成
- `--score-sheet-name <名称>`：自定义得分汇总 sheet 名（默认：源为班级小题明细→「班级小题得分」，否则沿用源 sheet 名）

依赖：Python 3 + openpyxl。本机 openpyxl 安装在 E 盘 `pylibs`（用上面的 PYTHONPATH）；
换电脑时先 `pip install openpyxl`（清华镜像：`-i https://pypi.tuna.tsinghua.edu.cn/simple`）。

## 输入：两种已验证的导出版本（脚本自动识别，无需指定）

| | 旧版（补充练习） | 新版（诊断练习） |
|---|---|---|
| 文件1 | `<班名>-英语-答题明细*.xlsx` | 同左 |
| 文件2 | `<班名>-班级小题明细-*.xlsx` | `<班名>-学生得分明细-*.xlsx` |
| 答题明细sheet | 学生明细-题号排序/正确率排序、客观题填涂、学生错题汇总 | 学生明细-题号排序/得分率排序（多key列）等 |
| 得分明细列 | 序号…主观题正确率 + 题号1~N | 序号…校次/班次/客观题/主观题 + 题号1~N |

识别规则（内置，能适应导出版本变化）：文件名含「答题明细」→ 答题明细文件；其余 xlsx → 得分明细文件；
按文件名中的 `高三N班…` 班级配对并按班名排序先后拼接。

## 输出结构

- 第1个sheet：**得分汇总**——各班得分明细纵向拼接，每班保留自己的标题行+表头行；
  纯数字题号表头按答题明细的「题型」列改写为 `阅读理解1`、`信息匹配16`、`单选题3` 等
  （改写后表头换行显示，行高自动设为28.8磅）。
- 其余sheet：答题明细的各sheet（题号排序/正确率或得分率排序、客观题填涂、学生错题汇总），同样各班纵向拼接。
- 字体/边框/填充/列宽/合并单元格（学生明细的纵向合并）全部从导出原样复制。

## 性能（2026-10-02 AFR侧优化版，实测84秒→26秒）

- 样式复制改 `_style` 整体直拷（一次赋值替代6次属性深拷贝）
- 校验阶段每个源文件只加载一次（旧版同一明细文件被重复加载 4 sheet×N 班次）
- 校验读取改 read_only 流式值矩阵 + `reset_dimensions()`（学校导出文件 dimension 常只标 A1）；含纵向合并的"学生明细"表仍用普通模式（read_only 不解析合并单元格）
- 逐格访问改 iter_rows 顺序流式

## 完成标准

脚本输出末尾必须出现 **「校验结果： 全部通过」** 才算成功（内置与原始文件的逐格全量比对、
题号表头改写校验、行数守恒校验）。任何 FAIL 都不能交付，需修复重跑。

## 注意事项

- 原始文件只读，绝不修改；输出文件已存在时用 `--backup` 备份旧版。
- 输出路径若被 Excel 打开会写入失败（Windows 锁）——关闭对应 Excel 窗口后重试。
- 学生明细里 57 与 57.0 这类 int/float 差异显示相同，校验已做容差，不是数据错误。
- 题型映射取自第一个班的答题明细；各班不一致时以第一个班为准（脚本会警告）。
- 本技能由 ZCode 于 2026-10 创建；ZCode 内自动触发的安装版：`C:\Users\Delphi\.agents\skills\xuece-4in1\`。
