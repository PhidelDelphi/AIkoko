## 推荐体验路径

1. 双击仓库根目录 `启动服务器-免Python.bat` 启动系统；
2. 「受绳」⚙ → 导入 `样本卷-答题明细.xlsx`（两个班成绩与逐题得分率）；
3. 「致远」→ ⚙ → 🤖 导入 `样本卷-合并.json`（各板块一次到位）；
4. 「致远」选中任一语篇 → 六步研读课堂；「就砺」点击题号圈画讲评；
5. 「参省」输入任一学生姓名（如：池知鼎、鄢慎舒、林桢新）→ 自动匹配成绩生成雷达图。
