# 「知明」· 高中英语试卷智能讲评系统 —— 作品简介

## 一、作品简介

「知明」·高中英语试卷智能讲评系统，名取《荀子·劝学》"则知明而行无过矣"，口号"假AI之善物，致学之知明"。系统秉持"善假于物"的人机协同理念，将国产大模型（智谱GLM）融入试卷讲评全流程：纯前端、离线优先，一个浏览器即可运行；以《劝学》八字命名的八大版面——须臾、受绳、就砺、致远、青蓝、跬步、博见、参省，覆盖课前预热到考后复盘的完整闭环。

## 二、解决问题

直击讲评课六大痛点：成绩散落多表，见分不明位；评讲"讲过即止"，错因不析、一错再犯；语篇教学重词轻篇，脉络难显；作文一稿定分、只评不升；拓展选文费力、真题讲完即弃；学生只刷不省、缺乏复盘。让教师从翻卷统计中解放出来，让学生从"听评讲"走向"自主勘破错因"。

## 三、实现功能

**受绳**：成绩Excel一键导入，等级着色、奖牌榜、隐名投屏；**就砺**：正确率四色分级、Split文题对照分栏圈画、错因归类并生成"同陷阱·新语料"变式训练；**致远**：试卷PDF自动识别语篇，六步研读课堂；**青蓝**：作文八步评讲、五维雷达与升格建议；**跬步**：知识笔记沉淀；**博见**：语篇话题与文化拓展展品，AI稿教师审定后上墙；**参省**：考后自动匹配成绩，生成雷达图与行动计划。AI分析JSON一键分发，数据自动流转。

## 四、应用效果

系统已在高三英语课堂常态化应用：试卷解析由手工约2小时压缩至3分钟；讲评课"数据定讲点、变式当堂练"，讲过即练；学生人人生成错题归因与行动计划，教师批阅一键完成；真题语篇延展为文化阅读素材。数据本地存储、一键隐名保护隐私；零安装、零费用、离线可用，普通教室浏览器即可开课，具备区域推广条件。
